# Render CSS Matrix Reconciliation Ledger

Date: 2026-07-10

Scope: Task 1 from `plans/2026-07-10-full-matrix-reconciliation-root-handoff-implementation.md`.

This ledger reconciles every row from
`plans/2026-07-08-render-css-support-matrix.md` against the current
`surgeist-render` code and tests. Status values mean:

- `Supported`: implemented in the current render contract and covered by tests.
- `Diagnostic`: represented as a render-facing concept but rejected through a
  typed diagnostic, capability flag, or unresolved-resource diagnostic.
- `DeferredToRoot`: root/style/layout/text/runtime must resolve or materialize
  the value before render sees ordinary render-ready input.
- `FutureRender`: render-owned work remains intentionally unimplemented by the
  completed sequence.
